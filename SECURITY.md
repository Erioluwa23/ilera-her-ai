# Security & health-data policy

Do not commit API keys, credentials, production health data, recordings, or personally identifiable user information.

The current prototype stores cycle logs locally in the user's browser. N-ATLAS credentials belong only in server-side deployment environment variables.

Report security issues privately to the project owner rather than opening a public issue containing sensitive data.

## Clinical safety
ÌleraHer is an educational and triage-support prototype, not a diagnostic system. Safety rules and health content require qualified clinical review before real-world clinical deployment.
