# Competition validation plan

Target: at least 50 consented, documented user interactions.

Measure:
1. Task completion for period logging.
2. Voice intent/transcription accuracy by supported language.
3. Comprehension of health guidance.
4. Safety-rule false negatives/false positives using clinician-reviewed scenarios.
5. Response latency and low-bandwidth usability.
6. User-reported privacy comfort and usefulness.

Never include names, phone numbers, raw intimate-health narratives, or voice recordings in public validation artifacts. Aggregate results and obtain explicit consent.
